Privacy policy

Applies to the personal-use Hermes Agent Google integration client described at this application's home page.

Who operates this

A single individual account owner, for their own use. There is no company behind this deployment, no server, and no other user. Contact: mr.anthonyong@gmail.com.

Google data this client accesses

Only the data belonging to the account owner's own Google account, within the scopes the owner explicitly granted at the consent screen:

  • Calendar — event and calendar data of the owner's calendars.
  • Gmail — messages and attachments in the owner's mailbox.
  • Drive, Docs, Sheets — files owned by or shared with the owner.
  • Contacts — the owner's contact list, read-only.

Each access happens because the owner asked for a specific task. There is no background harvesting, no scheduled bulk export, and no access by anyone other than the owner.

Where that data is stored and processed

  • Processing happens locally on the owner's own computer.
  • Google API traffic goes directly from that computer to Google over TLS.
  • Downloaded content, generated files, configuration and conversation logs remain on the owner's local disk, in the owner's own user directory.
  • Credentials (OAuth tokens and API keys) are stored in local files with restrictive permissions and are never sent to any destination other than Google's token endpoint.

What is not done

  • No selling, licensing, advertising use, or profile-building on Google user data.
  • No transfer of Google user data to any third party.
  • No human review of the owner's messages or files by anyone.
  • Nothing is manually cached beyond the local files described above.

Revocation and deletion

The owner can revoke the authorisation at any time at myaccount.google.com/permissions, which immediately stops new API calls. Anything already written to the owner's own disk is deleted by the owner, at their discretion — that disk is theirs.

Changes

If this policy changes, the updated version is posted on this page.
