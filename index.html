Hermes Agent

Google integration client — personal-use OAuth configuration

What this application is

Hermes Agent is an open-source AI agent framework by Nous Research that runs on the user's own computer — in a terminal, a desktop app, or a messaging surface such as Telegram. It is not a hosted web service. This page documents the Google Cloud project and OAuth client that let a single person's local Hermes instance act on their own Google account.

What this OAuth client does

The instance on this client machine uses the granted scopes for personal automation, specifically:

  • Google Calendar — create, list and update the user's own events and reminders. Example: a recurring "pay monthly bills" event on the first day of each month.
  • Gmail — read, search and send mail on the user's own mailbox when the user asks for it, such as triaging a thread or drafting a reply.
  • Google Drive, Docs and Sheets — upload and organise files, and create or append to documents and spreadsheets the user names.
  • Google Contacts — read-only lookup of the user's own contacts to resolve names and addresses.

Every action is initiated by the account owner, on the owner's own hardware, and the requested scopes are limited to that owner's account. No other Google account can authorise this client.

Where the data goes

  • Configuration, logs, transcripts and downloaded files stay on the user's own machine.
  • API requests are sent directly from that machine to Google's APIs over HTTPS.
  • Nothing read from Google is published, resold or shared with third parties.
  • OAuth tokens are stored in a local file on the user's machine and are never transmitted anywhere else.

Revoking access

The account owner can end this authorisation at any time at myaccount.google.com/permissions, where the app appears under the name shown on the consent screen.
