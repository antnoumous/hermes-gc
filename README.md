# hermes-gc

Static pages required by the Google Cloud OAuth consent screen (Branding → App domain)
for the personal-use Hermes Agent Google integration client.

Served by GitHub Pages at:

- Home page: https://antnoumous.github.io/hermes-gc/
- Privacy policy: https://antnoumous.github.io/hermes-gc/privacy.html
- Terms of service: https://antnoumous.github.io/hermes-gc/terms.html

Google's requirements being met here:

- A publicly accessible home page describing the app's functionality, no login required.
- A privacy policy hosted on the same domain as the home page, linked from the home page,
  and identical to the URL entered on the consent screen.
- The home page links to both the privacy policy and the terms of service.

Nothing here is built or run; three HTML files.
